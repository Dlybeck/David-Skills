# Codex reviewer isolation

Read before dispatching an independent reviewer from a Codex developer context. Inspect the
actual tools available on this surface; the skill does not install a delegation service.

On the native collaboration surface exposing `spawn_agent` and `fork_turns`, create a new agent
with `fork_turns: "none"`. Supply an explicit reviewer brief containing only the pinned repository,
base/head, settled requirements/authority, source access, and this skill. Do not reuse an agent
that handled implementation or a previous review. Leave model selection to the host/user policy.

Other Codex surfaces may expose different controls or no independent delegation. Use only their
documented fresh-context mechanism; do not invent launch flags or treat a compacted developer
session as independent. If no verified clean-context route fits the active budget, return that
gate unmet. Wait for the review through supported completion waiting, not repeated status calls.
