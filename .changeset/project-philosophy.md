Each project can have a philosophy file, `PHILOSOPHY.md`, so every chat starts from the same footing on what the project is for. `philosophy-review` now starts the file (from the owner's story, never by asking for a philosophy), hardens it over time as his choices show more, and still does the deeper check against it. The file describes and never binds, and has a soft length limit of about a page. `setup` offers to start one through that skill, as an optional extra.
